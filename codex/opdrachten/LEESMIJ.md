# Opdrachten voor Codex

Elke opdracht is één bestand in deze map. Codex leest eerst `AGENTS.md` in de hoofdmap (dat gebeurt vanzelf), daarna de opdracht.

Zo start je een opdracht in Codex:

    Lees AGENTS.md en voer codex/opdrachten/<naam>.md uit. Werk in een eigen branch en open een pull request.

Elke opdracht heeft dezelfde vier kopjes: Doel, Bestanden, Gewenst gedrag, Klaar als. Claude schrijft de opdrachten en kijkt de pull request na.
